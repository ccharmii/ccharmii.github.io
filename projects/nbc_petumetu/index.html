[프로젝트 요약]

  • 목적: 사용자 지식 수준과 시간을 반영하여 논문 이해에 필요한 핵심 개념을 그래프로 제공하고 최적의 학습 경로를 설계하는 Multi Agent 서비스
  • 성과: Graph DB 기반 지식 추출로 Hallucination 억제, 사용자 긍정 피드백 75% 달성

1. 기존 문제점 분석

  • 최신 AI 논문의 높은 진입장벽과 선수 지식 부족으로 인한 학습의 어려움
  • 사용자 니즈 파악 (설문): 교육생/멘토 33명 대상 설문 결과, 85%가 시각화된 개념도를 필요로 함

2. Graph Database 설계 및 구축

  • 문제 인식: LLM 단독 활용 시 선수 개념 정보의 일관성이 낮고 실존하지 않는 개념이 생성되는 Hallucination 발생
  • 해결 방안: Neo4j 기반 Graph Database 구축 및 관계 정의
    • Semantic Scholar, Wikipedia 데이터를 활용하여 논문-개념 간 유기적 관계 구축
    • Paper, Keyword 노드와 PREREQ(선수지식), IN(포함), ABOUT(주제) 등 핵심 관계 설계
    • 결과: 구조화된 데이터를 통해 근거 있는 학습 경로 시각화 기반 마련
관계 유형 구조 의미 (Description)
PREREQ A → B A가 B의 선수 지식임 (B를 알려면 A를 알아야 함)
IN A → 논문 논문을 이해하기 위한 선수 개념이 A임
ABOUT 논문 → A 논문의 주요 제안/핵심 개념이 A임
  • 선수 개념 관련 서베이 논문 분석 진행 → 지식 그래프 관련 논문 리뷰 보기

3. Agent 구현 및 Context Engineering

  • 문제 인식: 과도한 정보 포함으로 인한 학습 효율 저하 및 개인화 정보(수준, 가용 시간 등) 미반영 한계
  • 해결 방안: 개인화 Keyword Graph Agent 구현
    • 순환 엣지 제거 및 입력 구조 표준화 전처리 수행
    • 사용자 수준, 학습 목적, 목표 시간을 반영한 Context Engineering 수행
    • 결과: 사용자의 배경지식에 맞춘 '필수 핵심 개념' 선별 및 추천

4. Web Search Tools 디벨롭

  • 문제 인식: 단일 검색 툴의 자료 부족, API 호출 과부하, 중복 제거 시 결과 유실 문제
  • 해결 방안: 통합 검색 및 데이터 기반 Reranking 시스템
    • Web(Serper), Video(YouTube), Paper(Semantic Scholar)를 통합하는 파이프라인 구축
    • 사용자 Preference에 따른 동적 max_results 조합 로직 설계
    • Score 로직 적용: (Quality * 1.5) + Preference Weight 기반 상위 자료 추출
  • 결과: 결과 유실률 0% 달성 및 에이전트 호출 비용 약 60% 절감
