TSP task 이해 및 오픈소스 기여

  • 성과: 성능 재현 및 H-TSP 공식 레포지토리 논리 오류 발견 및 수정 기여 (GitHub Issue 2건 반영)

1. 연구 및 재현

  • TSP (Traveling Salesman Problem): 노드와 노드 간의 거리가 주어졌을 때 모든 노드를 정확히 한 번씩 방문하는 최단 거리를 찾는 문제
  • 기존 방식의 한계 분석: TSP의 스케일이 커질수록 학습, 추론 시간이 크게 늘어나며 초기 해 품질이 전체 성능에 큰 영향을 미치는 문제를 확인
  • H-TSP 모델 도입: Divide-and-Conquer 방식을 활용해 전체 문제를 하위 문제로 나누어 해결하는 계층적 접근법 채택 및 성능 재현
  • 성능 비교 결과: 전통적 알고리즘(Concorde) 대비 정확도는 소폭 낮으나, 실행 시간을 100배 이상 단축하여 실시간 경로 계획 가능성 확인

1.5D CSP 기존 솔루션 개선

[프로젝트 요약]

  • 목적: 원재료(Material) 사용량 및 Trim Loss 최소화를 위한 1.5D Cutting Stock Problem 최적화
  • 성과:
    • 기존 CBC Solver 대비 Trim Loss 18% 절감, 연산 속도 52% 단축 및 과생산율 개선 (4.7% → 1.9%)
    • 합성 데이터 생성 파이프라인 구축

1. 문제 재정의

  • CSP (Cutting Stock Problem): 큰 Material을 여러 개의 Product로 자른다고 할 때 자를 때 자투리인 Trim loss와 총 Material 사용량을 최소화하는 문제
  • 기존 방식의 한계 분석: 기존의 선형 계획법(LP) 기반 Solver는 데이터 규모가 커질수록 계산 복잡도가 기하급수적으로 증가하며, 고정된 롤 형태의 제약 조건으로 인해 유연한 대응이 어려움
  • 2-Stage 1.5D CSP 문제로 재정의 (폭 분할 → 길이 분할)

2. 유전 알고리즘 제안 및 구조화

  • 계층적 염색체 설계: [Stage 1 Genes | Stage 2 Genes] 구조를 통해 폭과 길이의 연결 제약을 유전 정보에 반영
  • LP 기반 초기화: 랜덤 생성이 아닌 선형 계획법의 해를 초기 해로 사용해 알고리즘의 수렴 속도 향상
  • Fitness Function 설계
Fitness = Trim Loss + (Penalty Weight × Material Count)
항목 기존 CBC Solver 제안 방법론 (GA) 개선 결과
