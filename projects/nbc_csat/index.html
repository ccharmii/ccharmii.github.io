Naver Boostcamp 8th: 수능 국어·사회 문제 풀이 모델 개발

Role: Baseline 코드 설계 및 리팩토링, RAFT 방법론 구현 및 실험, Context Engineering
2025. 12 – 2026. 01 (3주)

GitHub Link Wrap-up Report Link

[프로젝트 요약]

  • 목적: 제한된 컴퓨팅 리소스 환경에서 4B 규모 추론 모델에 Test time scaling을 적용해 성능 극대화
  • 성과: 최종 Macro F1 Score 0.6701을 기록하며 단순 추론 대비 약 11% 성능 향상

1. Baseline 리팩토링

  • 문제 인식: Baseline 코드의 구조적 결함으로 인해 새로운 방법론 적용 시 불필요한 시간이 과도하게 낭비됨
  • 해결 방안:
    • Trainer, Preprocessor, Model Loader 등을 추상 클래스로 정의하여 모듈화
    • YAML 기반 Config 환경 구축으로 인자 변경만으로 새로운 방법론을 즉시 테스트 가능케 하여 실험 속도 가속화

2. Test Time Scaling을 통한 모델 지식 분류 및 최적화

  • 문제 인식: 모든 문제에 일괄적으로 RAG를 적용하기보다, 모델이 모르는 지식에 대해서만 선택적으로 RAG를 적용하는 것이 성능에 유리함
  • 해결 방안: Test 단계의 Sampling을 통해 모델의 지식 상태 분류
    • 지식 상태 분류: 동일 문항 5회 샘플링을 통한 답변 일관성 측정 (확신: Agreement == 1 / 혼란: Agreement < 1)
    • LLM as a Judge 기반 검증: 혼란 상태의 문항에 대해 Reasoning 분석을 수행하여 일관성 판단
    • 선택적 RAG 및 RAFT 활용: 검증 점수가 낮은 문항에 한해 RAG 컨텍스트를 제공하고 RAFT 모델로 최종 추론 수행
  • 결과: 4B Reasoning 모델 단순 추론(0.6027) 대비 최종 Macro F1 0.6701 달성

3. RAFT 구현 및 고도화

  • 문제 인식: 문제와 무관한 문서가 노이즈로 작용하여 단순 RAG 적용 시 성능이 하락(0.6027 → 0.5365)하는 현상 발생
  • 해결 방안: Retrieval-Augmented Fine-Tuning(RAFT) 도입 및 데이터 고도화
    • RAFT 적용: 모델이 관련 없는 문맥을 무시하고 필요한 정보만 보도록 학습 → 팀 내 공유를 위한 논문 리뷰 진행 (Tistory)
    • Knowledge Distillation: 상위 모델(30B)의 Reasoning Trace를 추출하여 학습 데이터 생성 및 4B 모델에 지식 증류
    • Context Engineering: 이중 추론 실패, 지문 과의존 등 모델의 오답 패턴을 분석하여 컨텍스트 최적화
  • 결과: RAFT 적용 시 단순 RAG 대비 성능 0.13 향상 (문서 필요성을 스스로 판단하는 모델 구축)
